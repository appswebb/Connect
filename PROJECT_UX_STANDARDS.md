# CONNECT — UX standards

- Keep primary social tasks easy to reach: feed, connect, chat and people discovery.
- Place secondary areas (rooms, lives, subscription, profile, settings and app download) in contextual navigation without removing capabilities.
- Use clear page headings, concise supporting text and one dominant action per section.
- Loading, empty, success and failure states must be distinguishable and actionable.
- Preserve form input and conversation context during navigation when practical.
- On mobile, use adaptive layouts and the existing bottom navigation; do not compress desktop columns.
- Forms need persistent labels, clear validation and explicit loading/disabled states.
